# ALTF4 - Guía de ejecución del proyecto

## Descripción

ALTF4 es una aplicación desarrollada con arquitectura Frontend + Backend:

- Frontend: Angular
- Backend: Spring Boot
- Base de datos: MySQL

---

## Requisitos previos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- Java 11 o superior
- Maven
- Node.js 18 o superior
- npm

Puedes comprobar las versiones con:

```bash
java -version
mvn -version
node -v
npm -v
